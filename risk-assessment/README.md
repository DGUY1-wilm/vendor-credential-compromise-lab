# Risk assessment

Executive-facing third-party access risk assessment for the fictional Acme
Widgets, mapped to NIST CSF 2.0 and SP 800-53 Rev. 5. This is the deliverable
aimed at risk/consulting roles: it turns the technical findings from the lab into
business-language risk, with severity ratings and a prioritised, cost-aware
remediation roadmap.
